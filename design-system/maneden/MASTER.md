# まねでん デザインシステム（MASTER）

UI UX Pro Max（`.claude/skills/ui-ux-pro-max`）の検索結果を出発点に、まねでん向けに決めた全ページ共通の基準。
ページ固有の上書きは `design-system/maneden/pages/` に置く。迷ったらこのファイルが正。

## 1. 方向性

**「明細書のように、数字が主役」** — 税金・手取りの計算サイトとして、源泉徴収票や給与明細のような
落ち着いた紙面に、計算結果の数字をはっきり見せる。派手さより「信頼できる道具」に見えることを優先する。

- UI UX Pro Max の推奨: スタイル _Data-Dense Dashboard_（金融・レポート向け、アクセシビリティ低リスク）、
  配色 _Trust blue + amber highlight_、書体 _Japanese Elegant（明朝見出し＋ゴシック本文）_。
- 採用しなかった推奨: 最初の検索で出た _Glassmorphism_ と手書き風フォント（Caveat）。日本語非対応・可読性低下・
  ありがちな見た目になるため不採用。

## 2. 避けること（ありがちな AI 生成デザイン）

- グラデーション文字（`bg-clip-text`）、インディゴ→スカイのグラデーション、ぼかしたグロー、メッシュ背景、方眼背景
- 色付きグラデーションの角丸アイコンタイル、ホバーで浮き上がるカード（`-translate-y` + 影）
- 「選ばれる理由」「3 ステップ」の同型カード 3 枚並び、全幅グラデーションの CTA バナー
- 中身のない装飾バッジ（✨ など）。アイコンは lucide の線画のみ、絵文字は使わない

## 4. 文字

- 見出し（h1・h2・結果の見出し）: **Noto Serif JP** 600/700（`--font-heading`）。明朝で「書類」らしさを出す。
- 本文・UI: **Zen Kaku Gothic New** 400/500/700（既存）。欧文・数字は Geist。
- 数字: すべて `tabular-nums`。主要な結果の数字は Geist 700。
- サイズ（モバイル → PC）: h1 28→44px / h2 22→30px / h3 17→19px / 本文 16px / 補足 14px / 最小 12px（注記のみ）。
- 行間: 本文 1.8、見出し 1.35。字間: 見出しは `tracking-tight` を使わない（和文は詰めると読みにくい）。

## 5. 余白・形

- 余白は 4px 基準。セクション間 64px（モバイル）/ 96px（PC）、カード内 20px / 24px。
- 角丸: `--radius: 0.375rem`（6px）。ボタン・入力・カードすべて同じ半径系。丸すぎる 16〜24px は使わない。
- 影は使わない。面の区切りは 1px の罫線と背景色の差で表す。
- 最大幅: 本文 680px、ページ 1152px（`max-w-6xl`）。

## 6. 部品（shadcn/ui ベース）

- ボタン: shadcn `Button`。主ボタンは藍の塗り、副ボタンは `outline`。高さ 44px 以上（タップ領域）。
- カード: shadcn `Card` を罫線のみで使う。ホバーは罫線色を `primary` に変えるだけ（移動・影なし）。
- ツール一覧: カードの格子ではなく、**目次のような行リスト**（アイコン・名前・1 行説明・矢印）。モバイルで縦に長くならない。
- 計算結果: 「明細」パターン。項目名と金額を点線リーダーでつなぎ、最後の「手取り」行だけ朱の二重下線。
- セレクト: 値ではなくラベルを表示する（Base UI `Select` に `items` を渡す）。
- フォーカス: `focus-visible` で 2px の藍リング。消さない。
- モーション: 150〜200ms の色・不透明度の変化のみ。`prefers-reduced-motion` で無効化。

## 7. レスポンシブ

- 確認幅: 375 / 768 / 1024 / 1440px。横スクロールを出さない。
- ツール画面: モバイルは「入力 → 結果」の縦積み、PC（lg 以上）は入力 1/3・結果 2/3 の 2 カラム。
- ヘッダー: md 未満はメニューをシートに格納。
