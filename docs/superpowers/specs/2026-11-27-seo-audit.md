# maneden.com SEO 監査（2026-11-27）

`seo-audit` / `cro` スキルの観点で、本番 https://maneden.com と本リポジトリを確認した結果。
SEO を最優先の要件とする。

## 調べたこと

- sitemap.xml の全 111 URL を取得し、ステータス・title・description・canonical・h1・robots・og:title・JSON-LD の型を一覧化
- レスポンスヘッダー（Vercel キャッシュ HIT、HSTS、brotli）、404 の挙動、トップの読み込みリソース
- `pnpm build` 後の静的 HTML（`.next/server/app/**.html`）で og/twitter メタを確認
- ラッコキーワードの流入統計: 獲得キーワード 104、うち 21〜50 位が 4・51〜100 位が 100、推定流入 0（立ち上げ期）

## 問題なし（維持する）

- 全 URL が 200・index,follow・自己参照 canonical・h1 は 1 つ・lang="ja"
- 404 は正しく 404 を返す。HTTPS + HSTS。CDN キャッシュ HIT
- ツール/ガイド/ロングテールのタイトルは検索意図に沿っており 30〜50 字程度
- 個別企業ページ（約 1,555 枚）をサイトマップに載せない方針は意図的（`app/sitemap.ts` のコメント）。維持する

## 見つかった問題（優先度順）

### P1. OGP 画像と og メタがほとんどのページで欠落・誤り
- ページ側で `openGraph` を書くとルートの `openGraph` が丸ごと置き換わるため、
  ツール 14・ガイド 3・年収別ロングテール・企業ページで **og:image / og:site_name / og:locale / og:type / twitter:image が出ていない**（ビルド後 HTML で確認: `/tools/nisa`）。
- 逆に `openGraph` を書いていないページ（/tools, /companies, /about, /disclaimer, /privacy-policy, /terms, /contact, トップ）は
  **og:title が「まねでん」、og:url がトップ URL、og:description が古いキャッチコピー**のまま。
- SNS・チャットでの共有時の CTR と、Google Discover 等での画像表示に直接効く。

### P2. 企業ページへのクロール導線が切れている
- `CompanyList` はクライアント側で 30 件ずつページングするため、**静的 HTML に出る企業リンクは各一覧の先頭 30 件だけ**。
  サイトマップ非掲載の方針と組み合わさり、業種で 31 位以下の企業ページは Google から見て孤立している。
- 同じ理由で `/companies` は全 1,555 社の全フィールドを RSC ペイロードに載せ、HTML が **約 447KB**（他ページは 40〜130KB）。

### P3. 構造化データの重複・不足
- ガイド 3 本で BreadcrumbList が 2 重（ページ側と `Breadcrumb` コンポーネントの両方が出力）。
- `/tools`・`/take-home`・`/furusato` の一覧ハブに ItemList がない（`/guides` にはある）。
- Organization の logo が SVG。Google のロゴ要件は 112px 以上のラスター画像。

### P4. メタ情報の細かな不備
- ガイドの title が「…｜まねでん | まねでん」とブランド名が 2 重。
- description が短すぎる: /terms 11 字、/contact 18 字、/about 28 字、/privacy-policy 31 字、/disclaimer 32 字。
- `siteConfig.description`（ルートの既定 description と OG）が「フリーランスや個人事業主のための…」のままで、現在のサイト（会社員向けツール・企業年収）を表していない。
- robots.txt の `Host:` は Google が無視する非標準ディレクティブ。削除する。

## 今回の対象外（理由）

- 個別企業ページのサイトマップ掲載: 運営方針として意図的に外しているため。
- 新規記事・ツールの追加: 順位が 21 位以下に集中しており、まずは技術的な土台と共有時の見え方を整える。コンテンツ拡充は次の段階で提案する。
- AdSense / GA の読み込み方式: 既に afterInteractive / lazyOnload で最適化済み。
