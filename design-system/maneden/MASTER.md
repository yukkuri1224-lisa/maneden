# まねでん デザインシステム（MASTER）

UI UX Pro Max（`.claude/skills/ui-ux-pro-max`）の検索結果を出発点に、まねでん向けに決めた全ページ共通の基準。
ページ固有の上書きは `design-system/maneden/pages/` に置く。迷ったらこのファイルが正。

## 1. 方向性

**「明細書のように、数字が主役」** — 税金・手取りの計算サイトとして、源泉徴収票や給与明細のような
落ち着いた紙面に、計算結果の数字をはっきり見せる。派手さより「信頼できる道具」に見えることを優先する。

リデザイン（2026-11〜）では Modern SaaS × Premium Fintech の **Calm Precision** として、次の 3 点で「静かで精密」を出す。
色や装飾は増やさない。

1. 操作できる部品の枠は 3:1 以上の `--input`、装飾の罫線は薄い `--border`。2 つを混ぜない
2. フォーカスは全部品で同じ「2px の藍の実線」（`focus-ring` / `focus-field`）
3. 和文の行間・改行を整え、数字はサイト全体で等幅（桁がそろう）

決定の根拠と変更前後の値: `docs/ui-reviews/design-system/spec.md`（PR 1）

- UI UX Pro Max の推奨: スタイル _Data-Dense Dashboard_（金融・レポート向け、アクセシビリティ低リスク）、
  配色 _Trust blue + amber highlight_、書体 _Japanese Elegant（明朝見出し＋ゴシック本文）_。
- 採用しなかった推奨: 最初の検索で出た _Glassmorphism_ と手書き風フォント（Caveat）。日本語非対応・可読性低下・
  ありがちな見た目になるため不採用。

## 2. 避けること（ありがちな AI 生成デザイン）

- グラデーション文字（`bg-clip-text`）、インディゴ→スカイのグラデーション、ぼかしたグロー、メッシュ背景、方眼背景
- 色付きグラデーションの角丸アイコンタイル、ホバーで浮き上がるカード（`-translate-y` + 影）
- 「選ばれる理由」「3 ステップ」の同型カード 3 枚並び、全幅グラデーションの CTA バナー
- 中身のない装飾バッジ（✨ など）。アイコンは lucide の線画のみ、絵文字は使わない

## 4. 文字

- 見出し（h1・h2・結果の見出し）: **Noto Serif JP** 600/700（`--font-heading`）。明朝で「書類」らしさを出す。
- 本文・UI: **Zen Kaku Gothic New** 400/500/700（既存）。欧文・数字は Geist。
- 数字: `body` に `font-variant-numeric: tabular-nums` を指定し、サイト全体で等幅。主要な結果の数字は Geist 700。
- サイズ（モバイル → PC）: h1 28→44px / h2 22→30px / h3 17→19px / 本文 16px / 補足 14px / 最小 12px（注記のみ）。
  文字サイズは Tailwind 既定の段階（12/14/16/18/20/24/30/36/48/60px）だけを使う。12px 未満（`text-[10px]` など）は使わない。
- 行間: 本文 1.8、見出し 1.35。Tailwind の各サイズの行間を `@theme` で上書きしている:
  `xs` 1.5 / `sm` 1.6 / `base` 1.8 / `lg` 1.7 / `xl` 1.5 / `2xl` 1.4 / `3xl` 1.35 / `4xl` 1.3 / `5xl` 1.15 / `6xl` 1.1。
- 字間: 見出しは `tracking-tight` を使わない（和文は詰めると読みにくい）。
- 改行: `:lang(ja)` の段落・リスト・dt/dd・見出しに `word-break: auto-phrase`（文節で折る）。
  段落は `text-wrap: pretty`、h1〜h3 は `text-wrap: balance`。1〜2 文字だけの行を作らない。

## 5. 余白・形

- 余白は 4px 基準。使う値は 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px。セクション間 64px（モバイル）/ 96px（PC）、
  カード内 16px（モバイル）/ 24px（sm 以上。`Card` の `--card-spacing`）。
- 角丸: `--radius: 0.375rem`（6px）の 1 系統。操作部品（ボタン・入力・セレクト・タブ列）は `rounded-lg`（6px）、
  その内側（タブ・セレクトの行・ツールチップ）は `rounded-md`（4.8px）、カードは `rounded-xl`（8.4px）。`rounded-2xl` 以上は使わない。
- 影: 紙面の中の要素（カード・タブ・ボタン）は影なし。面の区切りは 1px の罫線と背景色の差で表す。
  浮いている層（セレクトの一覧・シート）だけ `shadow-md` を 1 段使う。
- 固定ヘッダー（64px）の下に要素が隠れないよう `html` に `scroll-padding-top: 80px`（`scroll-pt-20`）。
- 最大幅: 本文 680px、ページ 1152px（`max-w-6xl`）。

## 6. 部品（shadcn/ui ベース）

- 操作部品の高さ: 標準 40px（`Button` default・`Input`・`SelectTrigger`・`TabsList`）、主要 CTA 44px（`size="lg"`）、
  小 32px（`size="sm"`）。32px 未満の操作部品は作らない（WCAG 2.5.8 の 24px を余裕をもって満たす）。
- ボタン: shadcn `Button`。主ボタンは藍の塗り、副ボタンは `outline`。
- カード: shadcn `Card` を罫線のみで使う。ホバーは罫線色を `primary` に変えるだけ（移動・影なし）。
- ツール一覧: カードの格子ではなく、**目次のような行リスト**（アイコン・名前・1 行説明・矢印）。モバイルで縦に長くならない。
- 計算結果: 「明細」パターン。項目名と金額を点線リーダーでつなぎ、最後の「手取り」行だけ朱の二重下線。
- セレクト: 値ではなくラベルを表示する（Base UI `Select` に `items` を渡す）。
- 入力欄・ラジオ・スイッチ: 枠は `border-input`（3:1 以上）。地は透明（ダークも同じ）。無効時は `bg-muted` + `opacity-50`。
- タブ: 列は `bg-muted`、非アクティブの文字は `text-muted-foreground`、選択中は `bg-card` + `ring-1 ring-input`（影なし）。
- フォーカス: `app/globals.css` の 2 つのユーティリティだけを使う。消さない。
  - `focus-ring`: 押せる部品。`outline: 2px solid var(--ring); outline-offset: 2px`（塗りボタンでも隙間を挟んで見える）
  - `focus-field`: 入力欄・セレクト。`outline: 2px solid var(--ring); outline-offset: -1px`（枠そのものが藍になる）
  - `ring-3 ring-ring/50` のような半透明のリングは使わない。
- モーション: 150〜200ms の色・不透明度の変化のみ。`transition-all` は使わず、変わるプロパティを列挙する
  （例 `transition-[color,background-color,border-color,box-shadow,opacity,transform]`、`transition-colors`）。
  `prefers-reduced-motion` で無効化。
