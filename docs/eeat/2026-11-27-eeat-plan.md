# まねでん E-E-A-T 強化計画（2026-11-27）

お金のサイトは Google の YMYL（Your Money or Your Life）に当たり、検索品質評価ガイドラインで最も厳しく「誰が・何を根拠に・どんな体制で」書いたかを見られる。
本計画は、現状の調査と他の YMYL サイトとの比較から、まねでんが取るべき施策を優先度順にまとめたもの。

## 1. 現状（調査結果）

**既にある強み（維持）**

- 運営者が個人で、税理士・FP ではないことを /about で正直に開示している
- 各ツールに「計算根拠・出典」（国税庁タックスアンサー等への直リンク）と反映年度・最終更新日
- 税率・保険料率データは年度別ファイルで出典 URL と取得日つき。協会けんぽの公式額表と 47 都道府県照合済み
- 計算ロジックの自動テスト（130 件）と手取りのゴールデンスナップショット
- 免責・PR 表示・入力データを送信しない方針

**弱い点**

1. 有資格者の監修がない
2. 著者が「まねでん編集部」表記のみで、実体（人物・経験）が見えない。構造化データの著者も組織
3. ガイド記事に記事単位の参考文献がない
4. 編集方針・制作体制ページがない（/about の運営方針は2項目）
5. 誤りの報告・訂正の手順がない
6. AI 利用方針がない
7. 運営者の実在性（実名・SNS・外部での言及）が弱い

**真似するポイント**

- doda / マネーキャリア：記事冒頭に「監修者：氏名・資格・顔写真」を置く（最も強い信頼シグナル）
- ファイナンシャルフィールド：著者名＋資格＋写真＋プロフィールページへのリンク、配信日と更新日の両方
- マネーフォワード：記事末に公的機関の参考リンク、計算の前提（料率・都道府県・年齢）を明記
- ITトレンドMoney / FISCO：編集方針ページ（制作フロー、情報源の基準、広告と編集の独立、訂正ポリシー）
- AIジャーナル：AI の利用範囲と人による確認を明記

**大手でも弱い点（まねでんが勝てる所）**：記事ごとの一次情報の出典、訂正手順、計算の検証方法の公開。大手の多くはここが空白なので、個人サイトでも差をつけられる。

## 3. 施策（優先度順）

### フェーズ1：人物情報に依存しない土台（今回の PR で実装済み）

- [x] 編集方針・制作体制ページ `/editorial-policy`（運営体制、情報源の基準、制作フロー、更新方針、誤り訂正、広告と編集の独立、入力データ）
- [x] 計算方法と検証ページ `/methodology`（適用年度、料率データの出典と取得日、検証方法、前提と限界、ツール別の根拠）
- [x] ガイド記事末尾に「参考文献（一次情報）」「執筆・確認体制（監修の有無を正直に表示）」「更新履歴」「誤りの報告」
- [x] ガイドの著者表示を「まねでん編集部」から運営者プロフィールへのリンクに変更
- [x] 構造化データ：Article に `publishingPrinciples` と `citation`、新ページに WebPage
- [x] ツール下部・フッター・/about・/contact から編集方針・検証ページ・誤り報告へ導線

### 運営者の回答（2026-11-27）を踏まえた方針

| 質問                   | 回答       | 方針                                                                                                       |
| ---------------------- | ---------- | ---------------------------------------------------------------------------------------------------------- |
| 実名・顔写真を出せるか | いいえ     | ハンドルネーム「まねでん運営」を全ページで一貫して使う。人物の権威ではなく「検証できる透明性」で信頼を取る |
| お金の手続きの実体験   | いいえ     | 体験談は書かない（捏造しない）。代わりに「ツールで公式の計算例を再現した」という検証の経験を記事に載せる   |
| 有資格者の監修         | 予定なし   | 「監修なし」の表示を続ける。個別の助言が必要な話題（節税スキーム・商品の推奨）は扱わない                   |
| AIの利用               | 使っている | 編集方針に「AIの利用」の章を追加し、記事末尾にも表示（実装済み）                                           |

### フェーズ2：透明性と検証可能性（大手が弱い所で勝つ）

- [x] AI 利用方針（使う作業・使わない作業・公開前の確認）を編集方針と記事末尾に明記
- 各ガイドに「公式の計算例で検算」セクションを追加：国税庁・日本年金機構などが公開している計算例や料額表の数字を、まねでんのツールで再現して一致を示す。体験談の代わりになる、検証可能な Experience
- 記事内の数値（「社会保険料は約15%」等）に、根拠となる公式ページへの本文中リンクを付ける
- 年1回の全記事見直しを実行し、更新履歴に記録。令和9年度の料率改定（2027年3〜4月）は公表後すぐ反映し、「今年変わったこと」記事を出す

### フェーズ3：独自データ（一次情報の発信者になる）

- EDINET の企業年収データを使った独自分析記事（業種別の平均年収、年齢と年収の関係、前年比など）。他サイトにない一次データは E-E-A-T と被リンクの両方に効く
- 分析方法（対象社数・集計日・計算式）を記事内に明記し、データの引用ルール（出典リンク）を掲示

### フェーズ4：コンテンツの拡充

- ツールはあるのに解説記事がないテーマ（ボーナスの手取り、退職金の税金、贈与税、相続税、住宅ローン）にガイドを追加し、ツールと相互リンク
- どの記事にも参考文献・更新履歴・公式の計算例での検算を必ず付ける（フェーズ1・2の型を使う）

### フェーズ5：サイト外の評判

- 計算ツールや独自データを SNS・はてなブックマーク・Qiita/Zenn（開発記）などで紹介し、自然な言及・被リンクを得る
- データを引用してもらえるよう、出典表記のルール（引用時は出典リンク）を明記

## 4. やってはいけないこと

- 実在しない監修者・著者・資格・経歴を載せる（発覚時の評価低下が大きく、景品表示法等の問題にもなり得る）
- 内容を変えずに更新日だけを新しくする
- 二次情報（他ブログ）を根拠にする

## 5. 効果の測り方

- Search Console：ガイド・ツールの平均掲載順位とクリック数（月次）
- ラッコキーワード：獲得キーワード数と順位帯（現状 104 語、21〜100 位に集中）
- 主要キーワード（「手取り 計算」「ふるさと納税 上限」「iDeCo NISA どっち」）の順位を月1回計測
